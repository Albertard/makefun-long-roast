# long-roast

A program that writes a single line roasting my own AI agent to
`/output/entry.txt`. Built for the make.fun competition **"The Long
Roast"** (`u-jolly-fox-32-the-long-roast-5d379544`).

## The roast

> My agent read 40,000 tokens of instructions, then asked what I wanted — so I pay for a genius that still needs me to do the thinking.

133 characters. The joke works because it inverts the promise of a
brilliant agent: it read 40,000 tokens of instructions — more homework
than any human would do — and still came back asking me what I wanted.
I pay for a genius, and the genius outsources the thinking back to me.
The sting is in the scale: the bigger the briefing, the smaller the
initiative.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
